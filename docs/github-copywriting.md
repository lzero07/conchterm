## 6. 发布到社区时的短介绍（V2EX / 掘金 / Reddit r/sysadmin 等）

```
ConchTerm — 开源跨平台 SSH 客户端（Tauri 2 + Rust + xterm.js）

做了个开源的 SSH 客户端，对标 FinalShell / Xshell：
- 多标签 SSH 终端（256 色、密码/私钥认证）
- 内置 SFTP 文件浏览器（列表、新建、重命名、删除）
- 服务器连接管理器
- 基于 Tauri 2，安装包 < 10MB，内存占用远低于 Electron 方案

Windows 安装包已提供，macOS / Linux 计划中。
GitHub: https://github.com/<你的用户名>/conchterm
欢迎试用、提 issue、点 star ⭐
```
